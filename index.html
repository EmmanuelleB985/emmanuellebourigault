About

I build multimodal AI systems that evaluate, adapt, and improve foundation models across vision, language, and 3D data. My current focus is on multimodal post-training, VLM evaluation, hallucination and faithfulness measurement, and scientific reasoning systems that connect model behaviour to reliable downstream use.

I completed my PhD at the University of Oxford's Visual Geometry Group, supervised by Prof. Andrew Zisserman, where I worked on multimodal learning, 3D reconstruction, and generative models. My work combines research engineering, large-scale data pipelines, model evaluation, and production-oriented deployment.

Research Focus

Multimodal Post-Training

Fine-tuning and adapting LLMs/VLMs using supervised fine-tuning, RLHF-style preference optimisation, DPO-style training, and domain-specific evaluation loops.

VLM Evaluation & Reliability

Evaluation pipelines for hallucination, retrieval faithfulness, visual grounding, cross-modal alignment, and regression testing of multimodal systems.

Scientific & Physical AI

Multimodal reasoning over diagrams, 3D structure, medical/scientific data, and action-relevant visual scenes, with emphasis on verifiable outputs.

Evaluation & Open-Source Software

mmeval-vrag: Multimodal RAG Evaluation Framework

Open-source Python package for evaluating multimodal vision-language RAG systems. It measures retrieval quality, hallucination, answer faithfulness, and cross-modal alignment, supporting checkpoint comparison and regression testing for VLM/RAG pipelines.

pip install mmeval-vrag
PyPI → GitHub →

SciVLA-Verify: Agentic VLM Evaluation

In development: a Hugging Face benchmark and agentic evaluation toolkit for multimodal scientific reasoning over diagrams, plots, physics scenes, and action-conditioned visual tasks. Designed to generate verified reasoning traces and SFT/DPO preference data for post-training.
